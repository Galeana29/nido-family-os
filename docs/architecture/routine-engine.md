# Routine Engine

Mission: Care Plan + template + external commitments + actual events + current time + mode + previous plan → Resolved Day Plan.

`resolution-algorithm.md` is normative. `RoutineEngine.resolve(_:)` implements it.

## Placement rules
Exact (never moves), Anchor and Window (preferred time inside hard guardrails), Relative (offset from where
the reference is *planned* to end) and Dependent (offset from where the reference *actually* ended, falling
back to the plan with an `estimatedFromPlan` reason until reality is logged).

## Adjustment policies
Orthogonal to placement: duration-responsive (a short nap moves bedtime earlier, always clamped to its own
guardrails), external conflict, mode, manual override, care constraint.

## Priority
P0 safety/locked care; P1 anchor/external; P2 important; P3 flexible; P4 optional. Under pressure the engine
moves or omits from the bottom up. An occurrence at P3 or below is omitted (`cancelled`) when no slot fits;
anything more important surfaces an explicit conflict instead of disappearing quietly.

## Dependencies
Rule references form a graph resolved in topological order, with ties broken by declaration order so the same
template always resolves in the same sequence. A cycle is a configuration error and is rejected.

## Stability
Among valid plans the engine prefers the one closest to what the caregiver was already shown: movement below
the materiality threshold retains the previous time, but only while that time is still inside the guardrails.
Jitter erodes trust, and trust is the product.

## Determinism
No `Date()` inside the engine — current time is injected. No randomness, no locale parsing, no AI. Same
normalized inputs plus the same policy version produce the same output.

## Canonical scenario
`examples/sample-day.json` holds inputs only; the resolved day is generated by the engine and reviewed as
`examples/sample-day.snapshot.txt`. Run it with `swift run NidoScenarioRunner`.

Historical note: an earlier handwritten example claimed Nap 2 resolved to 14:45 from a Nap 1 ending at 11:31,
which is outside the rule's own +195 minute minimum. That defect is what motivated generated fixtures.
