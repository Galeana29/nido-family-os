# Intelligence Architecture

AI is interpreter/explainer, never schedule authority.

User language → transcription → CandidateAction → deterministic validation → confirmation when required → command → ledger → engine. Never LLM → database.

## Temporal ambiguity
exact: “at 2:13”
relativeResolved: “ten minutes ago”
approximate: “a little while ago”
ambiguous: “she already fell asleep”

Confirmation policy uses ambiguity class, reversibility and sensitivity — not fake numeric confidence.

All times/durations/deltas in explanations are injected from structured engine output into deterministic templates. AI may change tone around fields but never regenerate numbers.

Core operation never depends on AI.
