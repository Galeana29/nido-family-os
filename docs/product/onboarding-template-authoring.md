# Onboarding & Template Authoring

## Alpha
Import an explicit caregiver-approved template. Editing creates a new version/effectiveFrom; never mutate historical template meaning in place.

## Product onboarding — observe first
1. minimal profile/timezone
2. 3–7 day observation/logging period
3. system extracts a draft template
4. caregiver reviews windows/anchors/flexible items
5. activate only after approval

AI may interpret logs into draft rules; deterministic validation + human approval are mandatory.

Major transitions such as 2 naps → 1 create a new template version. Existing Operational Days retain the version they used.
