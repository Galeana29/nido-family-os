# Roadmap

## Phase 0 — Product proof

Goal: prove the core loop with fixture data.

Deliver:

- domain model;
- Routine Engine v0;
- scenario simulator;
- Today prototype;
- event ledger in memory;
- Figma 12-screen prototype.

Exit criterion:

One imperfect simulated day resolves correctly.

## Phase 1 — Personal daily driver

Goal: usable on one caregiver iPhone.

Deliver:

- SwiftData persistence;
- Today;
- sleep;
- meals;
- nursing/milk log;
- gradual program framework;
- Quick Log;
- local notifications;
- calendar read;
- grocery / prep;
- basic weekly insights.

Exit criterion:

Caregiver can run seven consecutive real days without needing the spreadsheet.

## Phase 2 — System-native experience

Deliver:

- nap Live Activity;
- widget;
- App Intents;
- Siri actions;
- Watch app;
- stronger attention manager.

Exit criterion:

Most frequent events can be operated without opening the iPhone app.

## Phase 3 — Shared household

Deliver:

- CloudKit adapter;
- CKSyncEngine;
- household sharing;
- conflict reconciliation;
- second caregiver.

Exit criterion:

Two caregivers can safely operate one household timeline.

## Phase 4 — Intelligence

Deliver:

- speech interpretation;
- CandidateAction framework;
- weekly narrative summaries;
- explanations;
- personalized-window suggestions.

Exit criterion:

AI reduces input friction without becoming a schedule authority.

## Phase 5 — Productization

Only after family use proves value:

- generalized onboarding;
- configurable routine templates;
- privacy/legal review;
- localization;
- broader research;
- App Store product work.
