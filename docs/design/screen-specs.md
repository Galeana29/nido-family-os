# Screen Specifications

## 1. Today — Normal

### Goal
Answer “what matters now?” in <3 seconds.

### Hierarchy

1. greeting/date;
2. day-state sentence;
3. Now Card;
4. next 2–3 events;
5. active program card;
6. caregiver window;
7. exceptions/conflicts if present.

### Day-state examples

```text
Everything is roughly on track.
Today is running about 20 minutes later — already adjusted.
The last nap was short, so bedtime may be earlier.
```

## 2. Today — Shifted

Show the same structure as normal.

Do not transform the screen into a warning dashboard.

Adjusted future items receive a lightweight indicator.

## 3. Now Card — Meal

Required fields:

```text
category icon
AHORA / NOW eyebrow
title
time window
menu summary
one-line instruction
primary CTA
secondary details
```

Primary action:

> Start meal

## 4. Meal Completion

Bottom sheet.

Question:

> How did it go?

Options:

```text
Nothing
Tasted
A little
Good
Wanted more
```

Optional secondary:

> Add detail

## 5. Nap Wind-down

Checklist can show:

```text
diaper
curtains
white noise
book
song
cuddle
program-specific step
```

Primary action changes as routine progresses.

## 6. Active Nap

Primary information:

```text
Nap 1
Started 10:43
time asleep 00:37
```

CTA:

> Woke up

Secondary:

> Edit start time

## 7. Nap Ended

The screen should not interrupt with a full-screen success page.

Update Today in place.

Optional explanation:

> The second nap moved 25 minutes because this nap ended later than planned.

## 8. Quick Log

Use large one-hand buttons.

Frequently used actions can reorder based on context without changing icon identity.

## 9. Plan Timeline

Week strip at top.

Selected day timeline below.

Visual semantics:

```text
exact      solid
anchor     filled marker
window     shaded span
flexible   outline marker
optional   reduced emphasis
```

## 10. Program Screen

Example gradual program.

Shows:

- current stage;
- today’s goal;
- history;
- criteria to hold/advance;
- source/owner of the program;
- controls to pause or revert.

Do not gamify stages as streaks.

## 11. Insights

Start with natural-language interpretation:

> Daytime nursing sessions decreased while logged solid-food intake increased slightly. Sleep stayed stable.

Then show data.

Never state causation solely from observational correlation.

## 12. Caregiver Window

When child sleep starts:

```text
This window is yours.
```

Options:

```text
Rest
Shower
One task
Personal time
Nothing
```

“Nothing” is a legitimate selection.
