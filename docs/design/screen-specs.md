# Screen Specifications — Alpha

All lifecycle/rating language comes from `docs/vocabulary.md` and String Catalogs.

## Today
Answer what matters now in under 3 seconds: day state, Now Card, next 2–3 occurrences, relevant active program, caregiver window/conflict if needed.

## Meal completion
Nothing/Nada; Tasted/Probó; A little/Poquito; Usual amount/Cantidad habitual; Wanted more/Quiso más. Never Good/Bad.

## Quick Log alpha
Sleep, Meal, Nursing/Milk, Diaper, Water, Weight, Note. Voice deferred to intelligence phase.

## Timeline
Exact solid; anchor marker; window shaded; flexible outline; optional reduced emphasis. Adjustment is secondary, never lifecycle.

Do not display `overdue` for parenting activities.
