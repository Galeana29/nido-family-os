# Content & Tone Guide

## Voice

NIDO is:

- calm;
- concise;
- adult;
- specific;
- non-judgmental;
- explainable.

NIDO is not:

- saccharine;
- infantilizing;
- alarmist;
- gamified;
- clinical unless context requires it.

## Never say

- “You failed.”
- “You broke the routine.”
- “Missed!” with a red failure state.
- “Bad day.”
- “Your baby should definitely…” when the system is only reflecting a configurable routine.

## Prefer

Instead of:

> You missed outdoor time.

Use:

> Outdoor time wasn’t needed in today’s simplified plan.

Instead of:

> Failed nap.

Use:

> She needed more support for this nap.

Instead of:

> AI optimized your schedule.

Use:

> I moved the second nap because the first nap ended later than planned.

## Progressive disclosure

Primary interface copy answers:

> What do I do?

Optional detail answers:

> Why?

Detailed sources/settings answer:

> Where did this rule come from?

## Medical language

If an instruction comes from a professional, attribute it clearly.

Example:

> Care Plan · Pediatrician instruction

Do not make NIDO sound like the clinician.
