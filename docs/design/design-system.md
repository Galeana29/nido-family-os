# NIDO Design System

Direction: **Scandinavian warm clinical** — calm, adult, precise.

Tokens:
brand.forest #426A5A
brand.soft #E5EFE9
canvas.warm #F8F6F1
surface.primary #FFFFFF
text.primary #202522
text.secondary #5A625D
accent.warm #C98567

`accent.warm` is decorative on light surfaces and is not approved as body/CTA text because contrast is insufficient.

Use `docs/vocabulary.md` for lifecycle/rating language. Do not create design-only lifecycle states such as overdue/adjusted.

Accessibility: SF/system typography, Dynamic Type, semantic colors, Reduce Motion, large one-hand targets, implementation-time contrast validation.

4pt spacing foundation; typical horizontal padding 20pt; radius hierarchy 10/14/18/24. Motion 200–350ms only where it explains causality.
