# Canonical Vocabulary · English / Español

Single naming authority for domain, design and localization.

## Lifecycle
upcoming → Upcoming / Próximo
ready → Ready / Listo
active → In progress / En curso
completed → Done / Terminado
skipped → Not done / No realizado
cancelled → Cancelled / Cancelado

`adjusted` is not lifecycle; derive an indicator from adjustmentReasons. Do not use `overdue` for parenting routine items.

## Meal quantity
none → Nothing / Nada
taste → Tasted / Probó
small → A little / Poquito
normal → Usual amount / Cantidad habitual
more → Wanted more / Quiso más

Never translate `normal` as Good/Bien: the scale describes quantity, not performance.

## Priorities
P0 safety/locked care; P1 anchor/external commitment; P2 important; P3 flexible; P4 optional.

## Product mantra
PLAN → NOW → DO → OBSERVE → LOG → RECALCULATE → NEXT
PLAN → AHORA → HACER → OBSERVAR → REGISTRAR → RECALCULAR → SIGUIENTE
